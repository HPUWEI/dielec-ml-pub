[Strong Correlations] The two most strongly correlated pairs are pm–vm (r=0.993) and vi–vm (r=0.991). These likely co-vary because pm (A-site/B-site ionic mass proxy), vm (molar/unit-cell volume), and vi (ionic volume) all scale with the size and mass of the constituent ions, so larger, heavier cations tend to occupy larger unit-cell volumes in the same perovskite-like framework.

[Redundancy] The cluster {pm, vm, vi, m} carries heavily overlapping statistical information, with pm–vm=0.993, vi–vm=0.991, vi–pm=0.984, pm–m=0.982, and vm–m=0.96; pd–va (r=-0.806) is a separate but notable inverse pair. These correlations indicate redundancy, but removal of any single feature should not be claimed from correlation alone, since each may still contribute unique non-linear signal to the Gradient Boosting model.

[Design Implication] Given this structure, a compact and informative feature set for predicting the dielectric property would combine one representative from the {pm, vm, vi, m} size/mass cluster (e.g., vm) with the inversely related pd–va pair, plus chemically distinct descriptors such as the electronegativity/ionization-energy features (blm, blsd, sm, ssd, com, cosd, Em, Ev, Esd, bvsdm, devvm, lsd, asd, GII) that are not collinear with the volume/mass block.
