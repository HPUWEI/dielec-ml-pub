[Strong Correlations] The two most strongly correlated pairs are pm–vm (r=0.993) and vi–vm (r=0.991). These likely co-vary because pm (A-site/B-site mass-related descriptor), vm (molar/unit-cell volume), and vi (ionic volume) all scale with the size and mass of the constituent ions, so larger, heavier ions tend to produce both greater ionic volume and greater molar volume.

[Redundancy] pm, vm, vi, and m form a tightly overlapping block (pm–vm=0.993, vi–vm=0.991, vi–pm=0.984, pm–m=0.982, vm–m=0.96), and pd–va (r=-0.806) is a strongly anti-correlated pair; these features carry largely shared statistical information. This overlap suggests redundancy, but removal of any single feature should not be decided from correlation alone, since non-linear or interaction effects in the Gradient Boosting model could still make each feature independently useful.

[Design Implication] Given this correlation structure, a compact and informative feature set for predicting the dielectric property would combine one representative from the pm/vm/vi/m size–mass cluster (e.g., vm or pm) with one from the pd–va pair (e.g., pd), and then add chemically distinct descriptors such as the electronegativity/ionization-energy features (blm, blsd, Em, Ev, Esd) and GII that are not part of these correlated blocks. This preserves the dominant size/volume and packing-related signal while retaining complementary electronic-structure information that the correlated cluster does not capture.
